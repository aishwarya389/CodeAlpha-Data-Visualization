# CodeAlpha Data Visualization

## Project Overview
This project performs data visualization and exploratory analysis on a Shopping Trends dataset using Python.

## Objectives
- Analyze shopping trends and customer purchase behavior.
- Visualize purchase amounts, customer age, product categories, and payment methods.
- Identify patterns using charts and graphs.
- Generate summary reports and cleaned data.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset
Dataset file: `shopping_trends_updated.csv`

Place the dataset inside the `data` folder.

## Project Structure
```text
CodeAlpha_DataVisualization/
│
├── data/
│   └── shopping_trends_updated.csv
├── outputs/
├── main.py
├── requirements.txt
├── README.md
└── .gitignore
```

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Install the required libraries:

```bash
python -m pip install -r requirements.txt
```

4. Run the program:

```bash
python main.py
```

## Output
The program generates visualizations, cleaned dataset files, category summaries, and a text report inside the `outputs` folder.

## Conclusion
This project helps understand customer shopping behavior through graphical representations and summary statistics.
